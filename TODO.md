# Finora delivery criteria

- Premium Finora landing page presents the tagline “Know your money. Control your future.”, supporting copy, Get Started and Explore Dashboard CTAs, feature sections and a polished footer.
- Authentication experience provides sign in, sign up, forgot password, reset-password messaging and logout, and private application views are not shown when signed out.
- Dashboard greets the user and dynamically calculates total balance, income, expenses, savings, savings rate, monthly comparison and budget usage from current transactions and budgets.
- Expense and income management supports working forms, validation, edit/delete, search/filter/sort, categories, payment methods, recurring status and immediate UI updates.
- Budgets support create/edit/delete, spent/remaining/progress calculations and visible warnings at 75%, 90% and 100% usage.
- Analytics displays category, monthly, income-versus-expenses, savings-trend and daily-spending visualizations with timeframe filters that change displayed data.
- AI Insights provides spending insight, saving suggestion, budget warning, unusual-spend detection and monthly summary content with the disclaimer “AI-generated insights are for informational purposes only and should not be considered financial advice.”
- Goals support create, edit, add-money and progress calculations with target dates and estimated completion copy.
- Transactions view provides a searchable, filterable, sortable ledger with distinct income/expense styling and action controls.
- Notifications support unread/read state and the settings view supports profile, currency, appearance and alert preferences.
- Light/dark mode persists, the responsive layout adapts to mobile, actions provide feedback, and seeded demo data makes the first dashboard useful.
- TypeScript/build checks pass, the route manifest is served, and the application starts on the configured runtime port without console-breaking errors.
